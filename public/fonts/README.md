# Self-hosted fonts

Latin subsets of three Google Fonts families, downloaded from fonts.gstatic.com (Martian Mono v6,
Newsreader v26, Schibsted Grotesk v7) and limited to the weight range the site uses (Newsreader keeps
its optical-size axis). All three are licensed under the SIL Open Font License 1.1.

Files are named after their contents; if one changes, change its name so the long cache header in
vercel.json never serves a stale copy.
